## 二、编译期修订（mvn compile）

| # | 问题 | 修订 |
|---|---|---|
| C1 | `ErrorWriter` 接口误放 rbac-api 但依赖 Spring/Jackson/Servlet，破坏契约层零依赖定位 | 接口移至 rbac-guard；rbac-api 保持纯契约 |
| C2 | `ClientIpResolver` 接口签名与实现不一致 | 以接口签名为准，实现适配 |
| C3 | 各子模块 pom 缺依赖（rbac-core/rbac-cache/rbac-auth/jackson-databind/spring-jdbc/spring-security-crypto/actuator 等） | 逐个补齐 |
| C4 | bcrypt 坐标写成不存在的 `at.pavlovov:bcrypt:0.10.2` | 改用 Spring Boot 自带 `spring-security-crypto` 的 `BCryptPasswordEncoder`，零额外依赖 |
| C5 | JJWT 0.12 `.clock()` 误传 `java.time.Clock` | 改用 `io.jsonwebtoken.Clock` 接口 |
| C6 | `ApiResponse` 缺 `ok()/fail()`；ErrorWriterImpl record 构造参数不匹配 | 补静态方法、修构造参数 |
| C7 | Caffeine 新版 API `.expireAfterWrite(long)` 已变更 | 改 `Duration.ofSeconds` |
| C8 | 单飞 `computeIfAbsent` 泛型推断报错 | inflight 类型改 `ConcurrentMap<String, CompletableFuture<Object>>`，内部显式强转 |
| C9 | Redis Pub/Sub：lambda 不能当 Executor / setSubscriptionExecutor 误用 | 改 `MessageListenerAdapter`，去掉 setSubscriptionExecutor |

## 三、运行期修订（启动链路）

| # | 问题 | 修订 |
|---|---|---|
| R1 | local profile 排除 `DataSourceAutoConfiguration` 导致 Mapper 链从根部断裂（PermissionResolver→PermissionCache→JwtAuthFilter 全崩） | 取消排除，local 改用 H2 嵌入式库 |
| R2 | pom 缺 H2 驱动 | rbac-bootstrap 加 `com.h2database:h2`（runtime） |
| R3 | Flyway SQL 不兼容 H2（`ENGINE=InnoDB`/`DATETIME(3)`/`ON UPDATE`） | 改标准 SQL（`TIMESTAMP`，去 MySQL 专属子句），同时保持 MySQL 8 可跑 |
| R4 | AuditMapper.xml `<=` 未转义；RelMapper 重复 statement id | `&lt;=`；拆成 `clearXxx` + `batchInsertXxx` |
| R5 | `PasswordPolicy` / `ErrorWriter` 无 `@Component` 无法注入 | 补注解 |
| R6 | AuthService/JwtService/JwtAuthFilter 硬依赖 `StringRedisTemplate`，无 Redis 时启动失败 | 改 `ObjectProvider` 优雅降级 |
| R7 | User/Role/Permission/IdentitySnapshot/AuditRecord 为 Java record，MyBatis 反射无 setter 映射失败、generatedKeys 回填炸 | 4 个 domain + AuditRecord 改 POJO；保留原 `xxx()` 访问器使调用方零改动；AuditMapper 去掉 useGeneratedKeys、补 resultMap |
| R8 | 各 Mapper `SELECT *` 在 H2 报 `Data conversion error` | 全部改显式列名（`<sql>` 片段复用） |
| R9 | JWT kid 错放 payload，验签找不到密钥 | 改 `.header().keyId(kid)`（JJWT 规范） |

## 四、设计缺陷修订（设计文档未覆盖、联调暴露）

| # | 问题 | 修订 |
|---|---|---|
| D1 | **无 Redis 时缓存不失效**：原设计只走 Pub/Sub 广播，单实例收不到自己的消息，login/logout 改 token_version 后新 token 30s 内被误拒 40101 | `CachePublisher` 发布时**先本地失效再广播**；AuthService 统一走 CachePublisher 入口，不再直接摸 Redis |

## 五、环境/工具修订

| # | 问题 | 修订 |
|---|---|---|
| E1 | 编辑器保存 Mapper XML 带 UTF-8 BOM，MyBatis SAX 解析报 `前言中不允许有内容`（IDEA 启动时暴露；jar 内旧副本无 BOM 故命令行能跑） | 6 个 Mapper XML 去 BOM；IDEA 需设 `File Encodings → Create UTF-8 files: with NO BOM` |
| E2 | PowerShell `curl` 是 `Invoke-WebRequest` 别名，参数不兼容 | verify.ps1 显式用 `curl.exe` |
| E3 | PowerShell 5 把 `java -version` 的 stderr 包成 NativeCommandError | verify.ps1 探测时临时 `$ErrorActionPreference=Continue` |
| E4 | V220 admin 的 BCrypt hash 初值错误 | Python bcrypt 生成正确 hash 后 `$2b`→`$2a` 适配 Java |
