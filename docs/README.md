## 决策记录

| 编号 | 决策 | 结论 |
|---|---|---|
| ADR-01 | 架构形态 | 模块化单体；一套 Spring Boot 应用，内部按模块隔离，多实例无状态部署 |
| ADR-02 | 组织模型 | 单组织；所有表不带 `tenant_id` |
| ADR-03 | 鉴权数据存放 | 单个 `PermissionSnapshot`（角色权限、用户角色、角色状态、权限启用、继承关系）+ 独立身份快照；Redis 广播失效 + 30 秒软 TTL，到期只触发重载、不丢数据 |
| ADR-04 | 权限抽象 | 统一用权限码表达；分 MENU / BUTTON / API / SYSTEM 四类；业务代码不引用角色概念 |
| ADR-05 | 权限范围 | 只做功能权限，不做数据权限（行级、字段级） |
| ADR-06 | 安全框架 | 不引入 Spring Security 框架；自研 JWT 过滤器 + 鉴权注解；密码哈希仅用 `spring-security-crypto` 单包 |
| ADR-07 | 并发模型 | 同步阻塞（内嵌 Tomcat）；不使用 WebFlux；不使用虚拟线程 |
| ADR-08 | 数据访问 | MyBatis 手写 SQL；不使用 JPA |
| ADR-09 | 审计 | 分 CHANGE（与业务同事务，不丢弃）与 SECURITY（独立落库，可丢弃但计数告警）两类 |
| ADR-10 | 升级路径 | RBAC0 起步；预留 `inherit_role_id` 字段与两个代码扩展点 |
| ADR-11 | 迁移管理 | Flyway 管理 DDL 版本 |
| ADR-12 | 性能口径 | 推导峰值 2,500 QPS；设计目标 2,000 QPS；验收 2,500 稳态 + 4,000 冲刺；鉴权类接口 P99 ≤ 30ms |
| ADR-13 | 令牌作废时效 | 多会话：登录不递增 `token_version`；登出、改密、停用使其递增并撤销该账号全部令牌。正常 ≤ 1 秒；Redis 故障 ≤ 30 秒；实例重启立即；数据库故障时受影响用户被拒 |
| ADR-14 | 缓存重载失败策略 | fail-open：继续用最后一份成功数据 + 强告警；已知状态变化用户仍拒绝；预留 `stale-policy` 开关 |
| ADR-15 | 覆盖式授权并发保护 | 乐观锁 `expectedVersion`（冲突返回 40950）+ 行级锁，两者同时使用 |
| ADR-16 | 客户端 IP | 由 `ClientIpResolver` 在可信代理边界内解析；限流、审计、告警复用同一结果 |
| ADR-17 | 角色继承字段语义 | `sys_role.inherit_role_id` 表示"从哪个角色继承权限"；不使用 `parent_id` |
| ADR-18 | 高可用边界 | MySQL / Redis / Nginx 全部单实例，无自动故障切换；保留扩展点约束 |
| ADR-19 | 权限码常量归属 | 分层：框架级（`*`、`sys:*`）放 `rbac-api`；业务级（`biz:*`）放各业务模块自己的常量类 |
| ADR-20 | 业务模块耦合面 | 业务模块只允许依赖 `rbac-api`；耦合点仅 `@RequiresPermission` 与 `AuditRecorder` |
| ADR-21 | 审计范围 | RBAC 域全量 + 业务域白名单（按影响面 × 可逆性判定）；业务接口须显式声明审计意图 |
| ADR-22 | 模块契约 | 严格分层：除 `rbac-bootstrap` 外，模块之间只依赖 `rbac-api`；`rbac-api` 定义应用服务契约，`rbac-core` / `rbac-auth` / `rbac-cache` / `rbac-audit` 提供实现，`rbac-bootstrap` 装配 |
| ADR-23 | 全局令牌作废 | 不新增全局版本字段与接口；全局作废通过密钥轮换执行：移除旧密钥后，旧令牌验签失败返回 40100（不是 40101） |
| ADR-24 | 首次登录 | `sys_user.must_change_password` 标记是否必须改密；初始 admin 由启动器按环境变量创建，不在 Flyway 中写密码 |
| ADR-25 | 权限缓存形态 | 权限相关事实合并为一个 `PermissionSnapshot`，失效时整体重载并原子替换；身份快照按 `userId` 单独缓存 |
| ADR-26 | 会话模型 | 多会话（登录不递增 `token_version`）；登出/改密/停用为账号级撤销；不引入 `jti` 与会话表 |
| ADR-27 | 外部服务接入 | 专用账号调用 `/api/auth/login` 取 JWT；判断自己用 `/api/auth/me` 或 `/api/auth/permit`，判断指定用户用 `/api/auth/permission-check`；不允许代最终用户操作 |

## 未决事项与已定假设

| 编号 | 问题 | 当前假设 |
|---|---|---|
| Q-1 | 是否需要对接 SSO 或第三方登录 | 不需要 |
| Q-2 | 是否存在存量用户数据需要迁移 | 无 |
| Q-3 | 访问令牌有效期与续期策略 | 已定：2 小时；多会话，登录不递增版本；续期不递增版本，只重读最新 `token_version` 与状态 |
| Q-4 | 审计日志保留期限 | 180 天 |
| Q-5 | 变更审计是否需要前后值快照 | CHANGE 类需要，SECURITY 类不需要 |
| Q-6 | JDK 与 Spring Boot 版本 | Java 21 + Spring Boot 3.x |
| Q-7 | fail-open 的代价需业务或合规书面确认（数据库长故障期间权限撤销可能延迟生效） | 已选择 fail-open |
| Q-8 | 备份与 binlog 是否已存放在数据库主机之外 | 假设已具备；不满足则 RPO≈0 不成立 |
| Q-9 | 角色继承算法的实现时机（阶段 0 就写 或 升级时再写） | 已定：方案甲，阶段 0 实现（见 05 §4.3、06 R-01） |
| Q-10 | 权限管理员能否修改自己的权限 | 允许，但受 FR-G3、FR-G4 约束 |
| Q-11 | 全局令牌作废方式 | 已定：密钥轮换，旧令牌返回 40100 |
| Q-12 | 初始 admin 密码来源 | 环境变量 `RBAC_ADMIN_PASSWORD`；首次创建时未设置或不符合密码策略则启动失败；账号已存在时只补绑缺失的 `SUPER_ADMIN` |

未决事项未拍板前不得开始写数据库脚本与接口实现。

## 术语

| 术语 | 含义 |
|---|---|
| 认证 | 判断"你是谁" |
| 鉴权 | 判断"你能不能做这件事" |
| RBAC0 | 用户 → 角色 → 权限三层模型 |
| RBAC1 | RBAC0 + 角色继承 |
| RBAC2 | RBAC0 + 约束（互斥、基数） |
| RBAC3 | RBAC1 + RBAC2 |
| 权限码 | 标识某个操作的字符串，如 `sys:user:create` |
| 身份快照 | 每实例内存中的 `userId → {tokenVersion, enabled, mustChangePassword, loadedAt, expiresAt}`，用于令牌作废与强制改密判定 |
| 权限快照 | 每实例内存中的一个不可变 `PermissionSnapshot`，包含角色权限、用户角色、角色状态、权限启用与继承关系；失效时整体重载 |
| 陈旧时长 | 缓存中最后一份成功数据距今的时间；fail-open 下是判断"权限判断有多旧"的唯一指标 |
| fail-open / fail-closed | 数据不可用时"继续放行"与"直接拒绝"两种姿态 |
| P99 | 100 个请求中 99 个的耗时不超过该值 |
| QPS / 在线用户数 | 每秒请求数 / 同时挂着的用户数（两者不是一回事） |
| RTO / RPO | 故障后恢复服务的最长时间 / 最多允许丢失的数据量 |
